# V-80HD 実機確認の手順（M3.5）

所要 15 分程度。結果は診断レポート（その他 → 診断 → レポート）を共有してテキストで渡す。IP とパスワードはレポートに出ない（PW は `••••`）。

## 準備
- iPhone：TestFlight の最新ビルド（build 8 以降。「診断」画面に「レポート」ボタンがあるもの）
- V-80HD：LAN CONTROL 端子を iPhone と同じネットワークに。本体 MENU → NETWORK で IP とパスワード（8 文字）を確認
- 本番セットじゃないこと（0B 領域の手動テストはスイッチが動く）

## A. LAN（必須）
1. 診断 → 「消去」
2. 接続画面で LAN、IP と PW を入れて接続
3. そのまま 10 秒待つ（同期・ポーリングが流れる）
4. **本体のパネルで** PGM を INPUT 3 に変える → アプリに追従するか見る
5. アプリで PST を INPUT 4 にする → 本体のパネルが変わるか
6. アプリの CUT を押す（FW 1.30 以降なら LAN 簡易制御コマンド `CUT;` で動く。ボタンが無ければ FW が古い＝VER の値を見る）。PGM/PST が入れ替わるか
7. 「その他 → コマンド送信・アドレス読取り」で
   - 読取り：アドレス `001500` サイズ `2`（PGM/PST の値。INPUT 3 なら `2B` が期待）
   - 書込み：アドレス `0C0100` データ `01`（タリー購読。`ERR` か、以後 `DTH:0C0000,…` が勝手に届くか）
8. 「診断 → レポート」→ 共有（AirDrop/メモ/何でも）→ テキストを渡す

見たいもの：`raw "…"` の行（プロンプト文字列、`<02>` の有無、ACK の実体、`VER:` の終端）、本体操作時の自発 `DTH:001500,..` の有無、`0C0100` の応答。

## B. USB（できれば。ケーブル 1 本）
1. V-80HD の USB STREAM 端子 ↔ iPhone（USB-C 直結 or Lightning カメラアダプタ）
2. 診断 → 「消去」→「レポート」→ 共有（**繋がなくていい**。端点一覧に V-80HD らしき名前が出るかだけ）
3. 出ていたら 接続画面 → USB → その端点を選んで接続 → 10 秒 → レポート
   - 繋がれば `機種 V-80HD、版 raw=…` の行が出る。出なければ `NO_RESPONSE`

見たいもの：端点の name / deviceName / driverOwner。これで USB MIDI クラスかが確定する（V-160HD / VR-120HD も同じ結論になる可能性が高い）。

## C. Bluetooth（任意）
1. 本体の Bluetooth を ON
2. 接続画面 → Bluetooth → 「Bluetooth MIDI デバイスを追加」→ 一覧に出る名前を控える
3. 出たら接続 → 10 秒 → レポート。アプリを一度バックグラウンド → 戻して、切れずに操作できるか

## やらないこと
- 0B 領域（パネルスイッチ）の総当たり。本番外のリハで 1 アドレスずつやる日を別に取る
- 公式アプリ・RCS との通信の比較

## 反映先
結果は `docs/VERIFY.md` の V-80HD 表へ。確定したら `core/profiles/v80hd.ts` の `capabilities`（usb / ble / tallySubscribe / cutAuto）と `lanAck` を更新し、必要なら V-160HD / VR-120HD の USB も同じ根拠で【事実】化する。
