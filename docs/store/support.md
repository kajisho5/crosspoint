# SW CROSSPOINT サポート / Support

## 日本語

**お問い合わせ**
GitHub の Issues からご連絡ください：https://github.com/kajisho5/crosspoint/issues
不具合の報告には、アプリの「その他」→「診断」→「レポート」で共有できるテキストを添えていただくと早く対応できます（IP アドレスとパスワードは含まれません）。

**よくある質問**

- **接続できない（LAN）**
  iPhone とスイッチャーが同じネットワークにあること、本体の NETWORK 設定で LAN CONTROL / DIRECT STREAM が有効で IP とパスワードが合っていることを確認してください。初回接続時に表示される「ローカルネットワーク」の許可が必要です（設定 › プライバシーとセキュリティ › ローカルネットワーク）。
- **接続できない（USB）**
  本体の USB STREAM 端子と iPhone を直結してください。Lightning 機はカメラアダプタが必要です。接続画面に端点が出ない場合は、「診断」→「レポート」の内容を添えてご連絡ください。
- **ボタンが無い機能がある**
  機種によって使える機能が異なります。アプリの「その他」→「About」→「対応機種」をご確認ください。
- **実機が無い**
  起動画面の「デモモードで試す」で全画面を操作できます。

## English

**Contact**
Open an issue on GitHub: https://github.com/kajisho5/crosspoint/issues
For bug reports, please attach the text shared from the app's More → Diagnostics → Report (it contains no IP address or password).

**FAQ**

- **Cannot connect (LAN)** — Make sure the iPhone and the switcher are on the same network, LAN CONTROL / DIRECT STREAM is enabled on the switcher, and the IP address and password match. The app needs the Local Network permission (Settings › Privacy & Security › Local Network).
- **Cannot connect (USB)** — Connect the switcher's USB STREAM port directly to the iPhone (Lightning models need a camera adapter). If no endpoint appears, send us the Diagnostics report.
- **A feature is missing** — Features vary by model. See More → About → Supported models.
- **No switcher at hand** — Tap "Try demo mode" on the first screen.
