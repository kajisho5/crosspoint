## SPEC・ボードとの差分（理由つき）
| 箇所 | SPEC / ボード | 実装 | 理由 |
|---|---|---|---|
| React Native | SPEC §8-1：0.87 | 0.86.3 | 【事実】`npx expo install` が SDK 57 に合わせて解決した版。SDK と揃えることを優先 |
| Gesture Handler | SPEC §8-1：3 | ~2.32.0 | 同上（SDK 57 の bundledNativeModules） |
| AUTO の下段表示 | ボード「1.0s · EMULATED」 | 「1.0s」 | SPEC v1.1 §9-2 で V-160HD は AUTO SW（0B001F）を直接送るため「EMULATED」は不要 |
| 保存済みデバイス | ボードに DEMO-SW-A/B が並ぶ | 初回は空（追加したものだけ表示） | 実アプリに架空の機器を最初から入れない。デモは「デモモードで試す」で起動 |
| オーディオ 1 ページ目 | ボード：IN 1, IN 2, USB, BT | IN 1, IN 2, IN 3/4, USB … | プロファイルの並び（SPEC §9-1・§9-4）に従う |
| SPLIT のサブ表示 | ボード「CAM 1 / CAM 2」 | ON / OFF | SPLIT のソースのアドレスは SPEC の表に無いため（推測で読まない） |
| DSK のサブ表示 | ボード「LUMA」「CHROMA」 | LUM-WHITE / LUM-BLACK / CHROMA | 下記「一次情報で確認したアドレス」の値の並びに合わせた |
| 外観モード | SPEC §11「Dark 既定」 | システム設定に追従（`userInterfaceStyle: automatic`） | Light・コントラスト強調はシステムカラーで自動対応。固定ダークにするかは要判断 |
| 画面の向き | SPEC §11：横向きは S1 専用レイアウト | M1 は縦固定（`orientation: portrait`） | 横レイアウトは後続マイルストーンで追加 |

## 一次情報で確認したアドレス（SPEC の表に無かったもの）
- V-160HD Remote Control Guide（https://static.roland.com/assets/media/pdf/V-160HD_Control_eng02_W.pdf）
  - DSK 1/2（`00 1F xx` / `00 20 xx`）：`02` DSK MODE、`03` KEY SOURCE（00–1F）、`05` DSK TYPE（LUMINANCE-WHITE KEY, LUMINANCE-BLACK KEY, CHROMA KEY）
  - PinP & KEY 1–4（`00 1B xx`〜`00 1E xx`）：`02` SOURCE（00–1F）、`03` TYPE
- V-80HD Remote Control Guide v1.03（https://static.roland.com/assets/media/pdf/V-80HD_Control_eng01_W.pdf）
  - DSK（`00 14 xx`）：`03` Mode、`04` Key Source（00–38）、`06` Type（Luminance-White, Luminance-Black, Chroma）
  - PinP & Key 1/2（`00 12 xx` / `00 13 xx`）：`03` Source（00–38）、`04` Type
