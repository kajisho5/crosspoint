## 4. アドレスマップの要点（SysEx 3 バイトアドレス）

値のエンコード（G p.19 行 1442–1446、各表の値域から）：
- 1 バイト 7bit。2 バイト値は aa×128+bb（例 12 34H = 2356）。「nibbled」の説明はあるが V-1-4K の表に nibbled と明記された項目は無い
- 負値は 7bit 2 の補数：1 バイト 62H = -30（HUE WIDTH）、30H = -80（NOISE GATE THRESHOLD）、4EH = -50、58H = -40、7FH = -1（LAST MEMORY / None）。2 バイト 7CH 0CH = -500、7FH 00H = -128、7EH 6AH = -150、71H 00H = -1920、77H 48H = -1080。3 バイト 7EH 6AH 00H = -19200、7FH 2BH 50H = -10800、7FH 79H 60H = -800（-80.0dB）、7EH 00H 00H = -INF
- 「#」付きアドレスは無い。複数バイト値は 1 行目に先頭アドレス、下の行に 2 番目以降の下位バイト（例 `00H 12H 02H` / `03H` = PGM/PST FADER LEVEL 2 バイト）
- 「reserved」はそのまま転記

| 用途 | アドレス | サイズ | 値域 | 意味 | 根拠 |
|---|---|---|---|---|---|
| PGM 選択 | 00 12 00 | 1 | 00–0F | HDMI IN 1–5, STILL 1–2, INPUT 1–8, BLACK（§5 参照） | G 行 374 |
| PST 選択 | 00 12 01 | 1 | 00–0F | 同上 | G 行 375 |

## 7. 機種固有の注意

- 受信の前提設定：MIDI Rx / Device ID / MVC のようなメニュー項目は **無い**（R SYSTEM メニュー 行 3966–4070、NETWORK メニュー 行 3861–3893）。LAN は NETWORK PASSWORD（8 文字）を設定しないと接続できない可能性（C 行 125–127）
- 対応 FW：Remote Control Guide は Version 1.00（2026-04-09）。iPad アプリは「システムプログラムを最新に」（C 行 20）。B の V-1-4K 行は「Version 1.0 and later」【推測：表紙 5 行目】
- CUT/AUTO はパネル操作モード（02 01 05 A/B か PGM/PST）で意味が変わる。A/B モード時は CUT/AUTO SW ASSIGN（02 01 06/07）で方向が決まる（R 行 3980–4002）
- PinP は PinP&KEY SW（00 0C 00）と PST/B 選択の組合せ。PinP ON PGM/PVW・ソース・時間の専用アドレスは無い。LAN の PPS/PPW:PinP1 がどのアドレスに対応するかは不明【不明】
- DSK キータイプは LUMINANCE-WHITE/BLACK のみ（クロマキーは PinP&KEY 側）
- HDCP ON で USB STREAM の映像/音声は出ない（R 行 3972）
- 時間指定の AUTO TAKE トリガ・時間指定の出力フェード SysEx は無い（ボタン押下 0B 00 1B / 0B 00 25 のみ）。LAN には `ATO:a,b;`（時間付き）と `FTB;` がある
- タリー自動送信（0C 01 00）は電源 ON 時 OFF。アプリ側で接続後に ON を書く必要
- ラベル編集対象は HDMI 1–5, STILL 1–2, PROGRAM, PREVIEW, BLACK, ROI 1–4（R 行 4058–4060）。INPUT 1–8 自体のラベルは無い
- B の MTRLV/AUXLV の応答コマンド名が `QAUXLV:`（原文ママ）など不統一（B 行 2234, 2261）
- 応答しないコマンド：RQ1 で不正アドレス/サイズは無応答（G 行 74–75）。LAN は ERR:4（invalid）が「他の設定に支配されて効かない」場合に返る
